# 湖南嘉遂安全科技有限公司官网

## 项目简介

这是一个为湖南嘉遂安全科技有限公司打造的专业企业官方网站。该网站采用现代化的单页面滚动设计，全面展示公司的服务内容、技术实力和联系方式。

## 主要功能

- **响应式设计**：完美适配桌面端、平板和手机端
- **平滑滚动导航**：固定导航栏，支持页面间平滑滚动和自动高亮
- **服务展示**：四大核心业务板块详细介绍
- **图片轮播**：服务板块支持多张图片切换展示
- **模态框放大**：点击图片可查看大图
- **移动端菜单**：汉堡菜单支持移动设备导航

## 技术栈

- **前端框架**：纯 HTML5 + CSS3 + JavaScript
- **样式预处理**：无（使用原生 CSS）
- **字体**：Noto Sans SC（思源黑体）
- **图标库**：Font Awesome 6.0.0
- **响应式**：CSS Grid 和 Flexbox

## 页面结构

1. **首页/欢迎屏** - 公司宣传语和核心价值展示
2. **关于我们** - 公司简介和团队介绍
3. **主要业务** - 四大业务板块：
   - 咨询服务
   - 风险管理
   - 教育培训
   - 技术产品
4. **联系我们** - 联系方式和服务覆盖区域

## 如何运行

1. 克隆或下载项目文件到本地
2. 使用浏览器直接打开 `index.html` 文件
3. 或者部署到Web服务器上访问
